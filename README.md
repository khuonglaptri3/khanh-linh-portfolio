# Portfolio Trần Thị Khánh Linh

Website portfolio tiếng Việt dựa trên CV được cung cấp. Dùng HTML, CSS và JavaScript thuần, triển khai bằng GitHub Pages, không cần cài đặt hay build.

## Xem trên máy

Mở `index.html`, hoặc chạy `python -m http.server 4173` và truy cập `http://localhost:4173`.

## Nội dung

Giới thiệu, học vấn, kinh nghiệm, kỹ năng, hoạt động và liên hệ. Tab kỹ năng hỗ trợ bàn phím. Phần đại diện dùng chữ KL; không đăng file hoặc ảnh CV lên website. File CV được giữ riêng trên máy và loại khỏi Git bằng `.gitignore`.

## Chỉnh sửa

- `index.html`: nội dung và liên kết liên hệ.
- `styles.css`: màu sắc, bố cục và responsive.
- `script.js`: menu mobile, tab kỹ năng và sao chép email.
- `favicon.svg`: biểu tượng trang.

Các dữ kiện học vấn và kinh nghiệm được giữ theo CV; không thêm chứng chỉ, dự án hay thành tích chưa được cung cấp.

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
